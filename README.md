# 趵突泉之光

山东大学趵突泉校区宿舍的**自助取水 / 洗澡 / 洗衣**三合一客户端。

这三个功能原本散在三个不同的 App 里——取水在「慧生活798」，洗澡在「胖乖生活」，洗衣在支付宝里的「智慧笑联」小程序。每次用都得先想「这个该开哪个」。这个 App 把它们收进一个界面：**三个服务各自独立登录、并列可用**，不用为了洗澡先去登录取水。

> ⚠️ **这是个人自用工具，不是任何一方的官方客户端。**
> 它通过各服务公开的 HTTP 接口通讯，不修改、不破解、不绕过任何鉴权或签名校验。
> 接口可能随时变更，服务方也可能不欢迎这类客户端——**请自行评估使用风险**。

## 功能

**三个服务并列**
取水、洗澡、洗衣各自独立登录，互不依赖。

**设备记忆与整理**
扫过或用过的设备自动记住；支持备注、按楼分组、置顶、长按拖动排序，也有「最近使用 / 按名称 / 手动排序」三种排序方式。

**实时占用水位**
洗澡页自动拉取本楼全部机器，按楼层分组，直接标出「空闲 / 使用中」，还能一眼看到同层哪几台是空的——不用站在浴室门口一台台试。

**扫码添加设备**
扫机器上的二维码即可入库；也能从已拉取到的设备名单里直接挑。

**桌面小组件**
深色 / 浅色 / 柔光玻璃三种样式，点一下直达。

**深色模式**
跟随系统 / 始终浅色 / 始终深色。

**自动检查更新**
启动时自动检查（12 小时最多一次），设置页里也有手动入口；发现新版本会列出更新说明，可直接在应用内下载并安装。更新源就是这个仓库的 Releases。

**其他**
登录过期自动提示并一键重登、历史订单查询、首次启动引导。

## 构建

**不需要 Gradle，也不需要 Android Studio。** 只用命令行工具链，全部免安装、免管理员权限。

需要的东西：

| 依赖 | 说明 |
|---|---|
| JDK 21 | 提供 `javac` / `keytool` / `jar` |
| Android SDK build-tools 35.0.0 | 提供 `aapt2` / `d8` / `zipalign` / `apksigner` |
| android-34 platform | 提供 `android.jar` |

> `d8` **必须是 35.0.0**：34.0.0 遇到匿名内部类会抛 NPE。

设置环境变量后直接跑：

```powershell
$env:ANDROID_SDK_ROOT = 'C:\path\to\android-sdk'
$env:WATER_KS_PASS    = '你的签名口令'      # 首次会自动生成 keystore.jks
.\app\build.ps1
```

产物输出到 `build\water-release.apk`。

> 如果 SDK 或 JDK 就放在仓库旁边的 `..\tools\` 下（`tools\android-sdk`、`tools\jdk*`），
> 连环境变量都不用设，脚本会自己找到。

构建流程本身没什么神秘的，就是六步：

```
aapt2 compile  →  aapt2 link（顺带生成 R.java）  →  javac
   →  d8 转 dex  →  把 classes.dex 塞进 APK  →  zipalign  →  apksigner
```

### 装到自己的手机上

构建完可以直接推给手机：

```powershell
adb install -r build\water-release.apk
```

`-r` 覆盖安装，已记住的设备和登录状态都会保留。

> 升级时签名必须一致，否则系统会拒绝安装。`app\keystore.jks` 是你的签名密钥，
> 已被 `.gitignore` 排除，请自己备份好——丢了就没法给已安装的用户发升级了。

## 几个踩过的坑

完整记录见 `CHANGELOG.md`，挑三个：

- **小组件尺寸**：Android 的格子公式是 `行数×70−30`（1 行 = 40dp）。填 84dp 会落在 1 行和 2 行之间，MIUI 向上取整成 2 行，内容却只按 1 行排——下面空一大片。而且**改 `widget_info.xml` 不会改变已经放到桌面上的实例尺寸**。
- **深色模式**：`attachBaseContext` 里改 `uiMode` 对系统是不可见的，得在 `onResume` 里比对当前模式再 `recreate()`，否则设置改了但界面不动。
- **一个「点了没反应」的接口**：结束用水调的是 `/dev/end`，参数里有个 `rcp`（receipt）。传 `true` 时服务端只回一份**回执快照**，反复调用返回的是一模一样的加密串——看起来成功，机器却毫无反应。传 `false` 才是真正执行结束。
