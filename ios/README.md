# 趵突泉之光 · iOS 版（Scriptable）

iPhone / iPad 上用它，**不需要 Mac、不需要开发者账号、不需要越狱**。

> 版本 **7.10.1** ｜ 与 Android 版功能对齐
> 这是本仓库自带的使用教程，也是你唯一需要看的文档。

---

## 为什么不是原生 App

iOS 应用必须在 **macOS + Xcode** 上编译签名才能装。本项目是在 Windows 上做的，
**产出不了 .ipa**。

所以 iOS 这一版用 **Scriptable**（App Store 免费）承载 —— 它能在 iPhone 上直接跑
JavaScript，还支持把脚本加到主屏幕当 App 用。功能上基本和 Android 版一致。

---

## 安装（约 3 分钟）

### 第 1 步 · 装 Scriptable

App Store 搜 **Scriptable**（作者 Simon B. Støvring，**免费**）并安装。

> 注意别装错。图标是一个深色背景上的 `{}`。

### 第 2 步 · 把脚本弄到手机上

**推荐：从本仓库复制**

1. 在 iPhone 上打开本仓库里的 [`ios/趵突泉之光.js`](./趵突泉之光.js)
2. 点右上角 **Raw**（或「原始文件」）→ 页面变成纯代码
3. **全选**（长按 → 全选）→ **拷贝**
4. 打开 Scriptable → 右上角 `+` → 进入新脚本 → **全选删掉** → **粘贴**
5. 点左上角标题（默认叫 Untitled Script）改成 `趵突泉之光`

> 直接打开 Raw 链接也行（这个链接带中文转义，可以整个复制）：
> `https://raw.githubusercontent.com/Baito-84170/baotuquan-light/main/ios/%E8%B6%B5%E7%AA%81%E6%B3%89%E4%B9%8B%E5%85%89.js`

**其他方式**

- **A. 微信 / QQ 传给自己**：把 js 文件发到「文件传输助手」，在手机上点开 → 用「文件」App
  打开 → 全选复制 → 粘进 Scriptable。
- **B. iCloud Drive**：把 js 存进 iCloud Drive，同上复制粘贴。
- **C. 电脑 + 手机同步**：本仓库克隆到电脑，用 AirDrop 把 js 发到手机。

> ⚠️ **粘贴一定要完整。** 脚本约 1100 行，被截断的话运行时会报「参数不正确」之类的怪错。

### 第 3 步 · 运行

在 Scriptable 里点这个脚本 → 出现主菜单就算成功。

### 第 4 步（推荐）· 加到主屏幕

Scriptable 里长按脚本卡片 → **添加到主屏幕** → 之后点图标直接跑，和 App 一样。

## 首次使用

打开后是主菜单：

```
趵突泉之光
山东大学趵突泉校区
──────────────────
💧  取水        未登录
🚿  洗澡        未登录
🧺  洗衣        智慧笑联小程序 · 免登录
```

「取水」和「洗澡」各需要一个账号，**两个账号互相独立**，第一次点会引导你登录
（手机号 + 密码 / 验证码）。

「洗衣」不用登录 —— 它直接跳支付宝的「智慧笑联」小程序。

---

## 三个功能怎么用

### 💧 取水（慧生活798）

1. 主菜单点「💧 取水」→ 按提示登录（手机号 + 密码）。
   **取水多一步图形验证码**：脚本会把验证码图片弹出来，看完关掉，再输入那 5 个字符。
2. 登录后点「查询设备」或直接扫机器上的二维码。
3. 把机器编号填进去（扫码得到的编号可以直接粘贴）。
4. 之后就能：**开始用水 / 查看状态 / 结束本次用水**。

> 「结束本次用水」修过一个坑：以前传给服务端的 `rcp` 参数不对，服务端只返回回执、
> 并不真的结束。现在是对的，点了就会停。

### 🚿 洗澡（胖乖生活）

1. 主菜单点「🚿 洗澡」→ 登录（手机号 + 验证码）。
2. 选「🚿 查询 / 开始洗澡」，脚本会：
   - 由机器号解析出设备、算价、取这台机器支持的支付渠道
   - 弹出确认框（**先看一眼机器屏幕**：显示「请扫码」= 空闲，可以开始；
     显示计时 / 余额 = 有人在用，别继续）
   - 下单 → 开锁
3. 洗完之后回「🚿 洗澡」菜单点 **「✅ 结束这一单」**。

> **⚠️ 关键：结束之后一定要付款。**
>
> 胖乖生活是**先用后付** —— 门开了、洗完了才结算。只结束不付款的话，这笔订单会
> 一直挂着，下一次洗澡时服务端会用 `code 2128`（有未支付订单需要完成）把新订单
> 整个拦掉。
>
> 本版本已经处理好了：**「结束这一单」之后会自动弹出付款窗口，点「去付款」跳到
> 支付宝完成这一笔。** 付完可以点「已付好了，检查一下」让脚本回查是否到账。
>
> 如果之前用旧版留过未支付的订单，现在点「开始洗澡」时会被拦住，并**直接给出
> 「去付款」入口**，付掉就能正常用了。

**几个补充说明**

- **免密支付暂时用不了**（机器上没有「支付宝免密」渠道），会走普通支付宝支付。
  想开免密得去官方「胖乖生活」App 里签约。
- 菜单里的 **「💰 支付这一单」** 可以随时补付当前那笔在途订单。
- 菜单里的 **「↩️ 撤销这一单」** 用于下单了但没解锁成功的情况，撤销不产生费用。
- 菜单里的 **「💳 支付方式」** 显示这台机器实际支持的渠道 —— 是从官方接口取的，
  不是猜的。

### 🧺 洗衣（智慧笑联）

不用登录。主菜单点「🧺 洗衣」会直接唤起支付宝的「智慧笑联」小程序洗衣页
（appId `2021001189641702`）。**需要装支付宝。**

## 功能一览

| 功能 | 说明 |
|---|---|
| 取水 | 登录、激活、查询状态、结束（`rcp` 参数已修正） |
| 洗澡 | 登录、解析设备、算价、选支付渠道、下单、开锁、**结束并结算付款** |
| 洗衣 | 跳转支付宝「智慧笑联」小程序洗衣页 |
| 未支付拦截 | 被 `code 2128` 拦住时直接给「去付款」入口，不再卡死 |
| 付款回查 | 付完可查 `order/pay_status` 确认到账 |
| 设备记忆 | 用过的设备自动记住，可重命名、删除、切换 |
| 状态查询 | 取水显示完整状态；洗澡显示设备健康状态 |

## 与 Android 版的差异

| 项 | Android 版 | iOS 版（Scriptable） |
|---|---|---|
| 安装方式 | 下载 APK 安装 | App Store 装 Scriptable，粘脚本 |
| 图形验证码 | 应用内显示 | 弹出图片预览，看完关掉再输入 |
| 扫码填 SN | 应用内直接扫 | 用相机 App 扫后回来粘贴编号 |
| 自动检查更新 | 有 | 无（重新复制脚本即为更新） |
| 桌面小组件 | 有 | 可用 Scriptable 自己写 |
| 版本提示 | 升级后弹「这次更新了什么」 | 无（看仓库 CHANGELOG） |

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 提示「未登录」 | token 过期了，菜单里「退出登录」再登一次 |
| 提示「参数不正确」 | 脚本被截断或改坏了，重新完整复制一遍 |
| 图形验证码弹不出来 | 网络问题，重试 |
| 洗衣点不动 | 确认装了支付宝 |
| 洗澡被拦「有未支付订单」 | 上一笔没付。点弹窗里的「去付款」，或菜单里的「💰 支付这一单」 |
| 跳转支付宝没反应 | 确认装了支付宝；也可打开官方「胖乖生活」App 手动结掉那笔 |
| 设备状态显示「—」 | 洗澡设备要先「用一次」才查得到状态 |
| 提示「扫码得到的序列号」相关错误 | 还没选过设备。先在菜单里「手动输入 SN」或「切换设备」选一台 |

## 隐私

- 账号 token 只存在 Scriptable 的**本地文件**里（`baotu/store.json`），
  不会上传到任何第三方地方。
- 计费完全在服务端，脚本只是替你发请求，**不影响扣费金额**。
- 脚本不含任何埋点、统计、上报。

---

## 开发说明

- 脚本是单文件、零依赖的纯 JavaScript，SHA-256 自己实现（已与 Python / Java 版
  逐字节比对一致）。
- 主菜单 → 三个功能各自独立，互不影响。
- 想改：直接在 Scriptable 里编辑即可，改坏了从仓库重新复制一份。
